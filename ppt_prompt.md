## 🎨 DESIGN GUIDELINES FOR GAMMA.APP

### Visual Consistency
- **Fonts**: Use professional fonts (Arial, Calibri, or system defaults)
- **Colors**: Stick to blue (#4f8bf9), green (#34c759), orange (#ff9500)
- **Layout**: Clean, uncluttered slides with ample white space
- **Images**: High-quality, relevant healthcare/technology imagery

### Content Best Practices
- **Keep text concise**: Use bullet points, not paragraphs
- **Emphasize key numbers**: Make metrics stand out visually
- **Use consistent formatting**: Same style for similar elements
- **Include visual aids**: Charts, diagrams, icons for better understanding
- **Maintain logical flow**: Each slide builds on the previous one

### Technical Specifications
- **Slide Ratio**: 16:9 standard presentation format
- **Font Sizes**: 
  - Titles: 36-44pt
  - Headers: 28-32pt
  - Body text: 18-24pt
  - Small text: 14-18pt
- **Image Resolution**: Minimum 1920x1080 for crisp display

### Special Effects (Optional)
- **Subtle animations**: For data reveals and transitions
- **Interactive elements**: Clickable areas for detailed views
- **Consistent transitions**: Smooth slide-to-slide movement
